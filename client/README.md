# Hearth

Frontend for My Restaurant App.

## Run

1. Start the API on `http://localhost:5140`
2. From this folder:

```bash
npm install
npm run dev
```

Open `http://localhost:5173`. Vite proxies `/api` to the backend, so you do not need CORS changes.

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
